# opencode-dictionary

完全オフラインの日本語辞書プラグイン。JMdict（日英対訳）・日本語ウィクショナリー由来の国語辞典
（約 124,000 見出し）・KANIDIC（漢字情報）・KanjiVG（筆順）を
バンドルしており、**実行中にネットワークへアクセスすることは一切ありません**。

## 機能

- チャットヘッダーの辞書ボタン、または本文テキストを右クリック →「辞書で引く」で検索ダイアログを開く
- 単語: 表層形・読み・品詞・意味を**辞書ごとにセクション分け**して表示
  - JMdict（共通語彙 約 38,000 見出し）: 英訳
  - 国語辞典（日本語ウィクショナリー由来 約 124,000 見出し・183,000 義）: 日本語による説明（出典付き）
- 漢字: 音読み・訓読み・英語意味・学年・画数（KANIDIC 約 10,000 字）＋ KanjiVG の筆順アニメーション（教育漢字 2,136 字、クリックで1画ずつ再生）
- 🔈 ボタンで読み上げ（ブラウザ標準の speechSynthesis / システムの日本語音声を利用。追加の音声インストール不要）
- サーバー側は起動後に gzipped 表をメモリへ展開して即答。辞書引き・筆順ともローカルのみ
- 検索ダイアログは `Ctrl+K` →「単語・漢字を引く」からも開けます

## 必要環境

- OpenCode Desktop（またはサーバー）と Node.js 20 以上
- 読み上げを使うには OS に日本語音声が入っていること（未インストールでも辞書機能は使えます）

## インストール

`~/.config/opencode/opencode.jsonc` の `plugin` 配列に追記します。

```jsonc
{
  "plugin": [
    "file:///絶対パス/opencode-dictionary"
  ]
}
```

リポジトリをクローンした場所に直接 `file://` を向けて構いません（ビルド済み GUI を同梱しています）。
設定を変更した場合は OpenCode を `/reload` してください。

## 使い方

1. 画面右上のヘッダーにある辞書アイコンをクリック、または回答本文の単語を選択して右クリック →「辞書で引く」
2. 検索ボックスに単語・かな・漢字を入力（入力中のたびに自動検索）
3. 漢字カードの左の図をクリックすると筆順が1画ずつアニメーションします
4. 🔈 でその語の読みを音声再生します

## データの更新

同梱データは `scripts/fetch-data.mjs` で再生成できます（開発時のみネットワークを使います）。

```bash
node scripts/fetch-data.mjs
```

出典とライセンスは [DATA.md](./DATA.md) を参照してください。

## テスト・ビルド

```bash
npm install
npm test        # vitest（バンドル済み実データに対する検索テスト）
npx tsc --noEmit
npx vite build  # dist/gui-experimental.cjs を再生成
```
